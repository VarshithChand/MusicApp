How to install an APK
  1. Open this page on your Android phone and tap Download APK.
  2. Open the downloaded file. If Android asks, allow installing from this source (your browser or Files app).
  3. Updating over an older version works only if both versions were signed with the same key. A TEST build is signed with a public test key, so uninstall it before installing a properly signed version.
  4. Some apps need extra Android settings. Each app explains them on first start.

Check a download: compare its SHA-256 (the “SHA-256” link next to each file) with the file you got.
